# ◇ AWS AI Practitioner (AIF-C01) Study Vault

A free, complete prep hub for the AWS Certified AI Practitioner (AIF-C01) exam, covering all 5 domains.

**Live site:** https://deven1003.github.io/study-vault-aws-ai-practitioner/

## What's inside

- **Core topics** for all 5 exam domains
- **Interactive AWS AI/ML architecture** (Bedrock and RAG)
- **Exam-style Q&A** and a **timed practice exam**
- **Hands-on labs:** first Bedrock prompt, RAG with Knowledge Bases, Bedrock Agents, Bedrock Guardrails, bias detection with SageMaker Clarify, drift detection with Model Monitor
- **Quick reference:** top decision patterns, SageMaker inference modes, the FM customization spectrum, exam-day tips
- **Downloadable PDF guides**

## Run locally

Everything is in a single `index.html`, so there's no build step:

```sh
git clone https://github.com/deven1003/study-vault-aws-ai-practitioner.git
cd study-vault-aws-ai-practitioner
# open index.html in your browser
```
